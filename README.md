# Library Management System

A simple C++ project to manage library users (guests, members, librarians) with a **permanent database** stored in a text file. Demonstrates **polymorphism**, **dynamic memory**, and **file I/O** in C++.

---

## Prerequisites

1. **Windows 10/11 (64-bit)**

2. **MSYS2 (UCRT64)**  
   - Install from [MSYS2 website](https://www.msys2.org/)

3. **G++ compiler (mingw-w64-ucrt-x86_64-gcc)**  
   - Install in MSYS2 terminal:

   ```bash
   pacman -Syu
   pacman -S mingw-w64-ucrt-x86_64-gcc

4. **Visual Studio Code**  
   - Install C++ extensions:
        - C/C++ (by Microsoft)
        - Code Runner (optional)
